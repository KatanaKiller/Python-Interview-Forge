    🔁Union-Find (DSU)DS
    class UnionFind:
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0]*n; self.cnt = n
    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]
    def union(self, x, y):
        px,py = self.find(x),self.find(y)
        if px==py: return False
        if self.rank[px]<self.rank[py]: px,py=py,px
        self.p[py]=px
        if self.rank[px]==self.rank[py]: self.rank[px]+=1
        self.cnt-=1; return True

    Use for: connected components, redundant edges, accounts merge, Kruskal MST.

    🔗Trie (Prefix Tree)DS
    class TrieNode:
    def __init__(self):
        self.children={}; self.end=False
class Trie:
    def __init__(self): self.root=TrieNode()
    def insert(self, w):
        cur=self.root
        for c in w:
            cur=cur.children.setdefault(c,TrieNode())
        cur.end=True
    def search(self, w):
        cur=self.root
        for c in w:
            if c not in cur.children: return False
            cur=cur.children[c]
        return cur.end

    Use for: word search, autocomplete, longest common prefix, replace words with roots.

    🏔️Dijkstra's AlgorithmAlgo
    dist={n:float('inf') for n in graph}
dist[src]=0; pq=[(0,src)]
while pq:
    d,u=heapq.heappop(pq)
    if d>dist[u]: continue  # stale
    for v,w in graph[u]:
        if dist[u]+w<dist[v]:
            dist[v]=dist[u]+w
            heapq.heappush(pq,(dist[v],v))

    With state: pq = (cost, node, extra_state). Use 2D dist: dist[node][state] for problems with extra constraints.

    Sliding Window

    When: contiguous subarray/substring · max/min length · K distinct characters

    02
    Two Pointers
    Medium

    When: sorted array · pair/triplet sum · palindrome · container water

    l,r=0,n-1
while l<r:
    if arr[l]+arr[r]==t: return [l,r]

    03
    Binary Search on Answer
    Hard

    When: "minimum X possible" · "max feasible X" · monotonic feasibility function

    lo,hi=min_val,max_val
while lo<hi:
    mid=(lo+hi)//2
    if feasible(mid): hi=mid
    else: lo=mid+1
return lo

    Fast & Slow Pointers
    Medium

    When: detect cycle · find middle · cycle entry point · happy number

    slow=slow.next; fast=fast.next.next

return False
    05
    Tree BFS (Level Order)
    Medium

    When: level traversal · min depth · zigzag · right-side view · connect nodes

    q=deque([root])
while q:
    sz=len(q)  # snapshot size!

    06
    Backtracking
    Hard

    When: all combinations · permutations · subsets · N-queens · Sudoku solver

    # Choose → Explore → Unchoose
def bt(state):
    if complete(state):
        results.append(state[:]); return
    for c in choices(state):
        if valid(c): state.add(c); bt(state); state.remove(c)

      🗣️Communication — What to Say
      

      ✓
      "Let me start with brute force to make sure I understand the problem..."
      

      ✓
      "I see a sliding window pattern here — O(n) should be achievable."
      

      ✓
      "Let me trace through this example before coding."
      

      ✓
      "Edge cases: empty input, single element, duplicates, negatives, overflow."
      

      ✗
      Coding immediately without verbalising your approach.
      

      ✗
      Silent for more than 60 seconds — always narrate your thinking.

      💎Python-Specific Wins
      

      ✓
      @cache for recursive DP — instant memoisation, zero boilerplate.
      

      ✓
      Counter(arr) frequency in one line. Supports arithmetic operations.
      

      ✓
      defaultdict(list) for graphs — no KeyError on new nodes.
      

      ✓
      deque for BFS — popleft() is O(1), list.pop(0) is O(n).
      

      ✓
      Negate for max-heap: heappush(h, -val)
      

      ✗
      list.insert(0,x) is O(n). Use deque.appendleft().
      

      ✗
      String += in loop is O(n²). Use list then ''.join().
      

      ✗
      [[0]*n]*m shares rows. Use [[0]*n for _ in range(m)].
